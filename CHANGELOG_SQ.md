# Changelog @sinequa/atomic-angular

All notable changes to @sinequa/atomic-angular that affect the user experience are documented here.

## What's Changed Between v0.2.5 and v0.2.10

### 🎯 Key Highlights

- **Smarter Filters**: Filters now handle overflow better and match your data more accurately
- **Improved Reliability**: Better error handling means fewer interruptions to your work
- **Enhanced Security**: Updated dependencies and resolved security vulnerabilities
- **Better Performance**: Framework updates provide a smoother, faster experience

---

## How to Update

To get these latest improvements:

1. Update your package dependencies
2. Clear your browser cache for the best experience
3. Check with your system administrator if you encounter any issues

## Need Help?

If you experience any issues with these updates or have questions about new features, please contact your system administrator or check the project documentation.

## [0.2.10] - 2025-12-05

### ✨ New Features

#### Better Filter Management

- Added smart overflow handling for filter bars when you have many filters

### 🔧 Improvements

#### Enhanced Assistant Experience

- Made the assistant feature more flexible and responsive to different user scenarios
- Improved assistant check functionality for better user interaction

## [0.2.9] - 2025-12-03

### ✨ New Features

#### Smarter Filter Matching

- Improved how filters match and work with your data columns (aliases are now supported inside the filters JSON configuration file)

## [0.2.7] - 2025-12-01

### 🛠️ Updates & Security

#### Framework Updates

- Updated to the latest Angular framework for better performance and security
- Resolved security vulnerabilities identified in dependency audit
- Updated core libraries for improved stability

## [0.2.6] - 2025-12-01

### 🐛 Bug Fixes & Improvements

#### Better Error Handling

- Improved handling of authentication errors (401 unauthorized)
- Added automatic retry mechanism when authentication expires
- Better error messages and recovery options
- Smoother experience when dealing with connection issues
