title: 📝 Recents Changes
---

The documentation is updated regularly to include the latest features, bug fixes, and enhancements.

### 🚀 New Features

* [filters](atomic-angular/components/filters): Added support for vertical rendering.
* [overflow-manager](atomic-angular/directives/overflow-manager.md): Added support for vertical overflow detection, allowing for better
handling of lists that exceed the visible area in a vertical layout.
* [Localization](mint/how-to/localization.md): Introduced a new feature for managing localization, including language switching and translation management.
* [In-Depth Mint Clone](mint/how-to/setup.mdx): A comprehensive guide to the Mint clone, detailing its structure, components, and functionalities.
* [Notifications](mint/how-to/notifications.md): Added a new notifications feature that allows users to receive and manage notifications within the application.

### ✨ Updates

* [preview](services/preview.md): Enhanced the preview service to support custom highlights and improved interaction with the preview iframe.
* [Aggregations service](services/aggregations.md): Updated to include methods for loading more aggregation items and opening aggregation nodes.  
* [App store](stores/app): Updated documentation to clarify the use of [`getAuthorizedFilters`](stores/app#getauthorizedfilters) for retrieving sorted aggregations based on a query name and added missing methods.
