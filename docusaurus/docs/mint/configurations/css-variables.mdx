CSS variables (also known as custom properties) are a powerful feature of CSS that allow you to define reusable values throughout
your stylesheets. They enable you to create a consistent design system and make it easier to manage and update your styles.

## Variables

### Typography

| Variable | Value(s) | Description |
|----------|----------|-------------|
| `--font-display` | 'Segoe UI', 'SF Pro Text', 'Aria', 'sans-serif' | Main display font family |
| `--text-xxs` | 0.625rem | Extra small text size |
