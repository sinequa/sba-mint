This document explains how to customize various aspects of the Mint application using the Sinequa Admin interface. Configuration is managed through JSON files in the "customization (JSON)" section of Sinequa Admin. Each configuration file controls a specific part of the Mint application.

## Configuration Files Overview

<img src={useBaseUrl('img/configurations/json.png')} alt='authentication' />

### 1. [routes](routes)

- **Purpose:** Defines the appearance and structure of the tabs in the "Search" section of the application. It also creates the associated routes used by the application.

<details>
<summary>Click to expand JSON example</summary>
```json

    {
        "path": "all",
        "wsQueryTab": "all",
        "icon": "fas fa-globe"
    },
    {
        "path": "html",
        "wsQueryTab": "html",
        "icon": "fa-brands fa-html5"
    },
    {
        "path": "pdf",
        "wsQueryTab": "pdf",
        "icon": "fas fa-file-pdf"
    },
    {
        "path": "doc",
        "wsQueryTab": "doc",
        "icon": "fas fa-file-word"
    },
    {
        "path": "xls",
        "wsQueryTab": "xls",
        "icon": "fas fa-file-excel"
    },
    {
        "path": "ppt",
        "wsQueryTab": "ppt",

    {
        "path": "txt",
```

- **Angular Routes Description:**
  - In Angular, routes are used to map URL paths to components. Each route defines a path and the component that should be displayed when the path is accessed. This enables navigation between different views or pages in a single-page application (SPA).
  - In Mint, the `routes` configuration allows you to customize which tabs are visible in the search interface and how users navigate between them.

### 4. general

- **Purpose:** Allows you to configure application logos without modifying CSS files. This simplifies branding and visual customization of the Mint application.

Today, the general configuration is limited to the logo customization, but it may be extended in the future to include other general settings.

<details>
<summary>Click to expand JSON example</summary>
```json
{
    "name": "Sinequa",
    "logo": {
        "light": {
            "small": null,
            "large": null
        },
        "dark": {
            "small": null,
            "large": null
        }
    }
}
```
</details>

### 5. assistants

- **Purpose:** Contains the configuration for the assistant feature. This enables you to customize the behavior and appearance of the assistant within the application.
For further explanations see the [Assistants Configuration](https://doc.sinequa.com/assistant/latest/index.html)

## How to Use

1. In Sinequa Admin, navigate to the "customization (JSON)" section.
2. Select the configuration file you wish to edit (`routes`, `filters`, `sources`, `general`, or `assistants`).
3. Modify the JSON as needed to customize the Mint application.
4. Save your changes and refresh the Mint application to see the updates.

---

For more details on each configuration, refer to the Mint and Sinequa documentation or contact your administrator.

### 6. features

- **Purpose:** Allows you to enable specific features that are disabled by default.

## Feature flags list

- `allowChangePassword`: enables the password modification on the SignIn component.
- `advancedSearch`: enables the advanced search option in the search bar autocomplete which opens a drawer with many ways of filtering.
- `filterLinkChildren`: makes the filter items to be linked between parent and children (i.e. selecting a parent also selects the children, or unselecting a child of a selected parent unselects it).
- `quickFilter`: allows direct clicking on any filter item to automatically apply it.
- `expandPreview`: adds an "Expand" button in the preview drawer to open a preview in a fullscreen dialog to have a bigger preview but also with an assistant or the search on the side.
- `editablepartition`: whether this is an editable partition.
- `allowChatDrawer`: enables the chat in the drawer.
- `showAggregationItemCount`: displays the item counts for aggregations.
- `userProfile`: user profile configuration, contains `enabled` to enable the feature and `customData` for any custom data to have in the profile form.

## How to Use

1. In Sinequa Admin, navigate to the "customization (JSON)" section.
2. Select the `general` configuration file.
3. Enable the desired features inside the `features` parameter.
4. Save your changes and refresh the Mint application to see the updates.

## Example

```json
{
    "features": {
        "allowChangePassword":true,
        "advancedSearch": true,
        "filterLinkChildren": true,
        "quickFilter": true,
        "expandPreview": true,
        "userProfile": {
            "enabled": true
        }
    },
    ...
}
```
