title: Pages

This is where the application pages are located as described in the routes file: _app.routes.ts_.

There are currently 2 main pages:
- **Home**, the home page
- **Search**, the search page. It is further divided into several other pages by existing tabs.

## Folder Structure: _Pages_

```ascii
📂pages
├── 📁assistant/
│   └── 🧩assistant.layout
│
├── 📁home/
│   └── 🧩home.component
│
├── 📁search/
│   ├── 📁all/
│   │   └── 🧩search-all.component
│   └── 🧩layout
│
├── 📁widgets/
│   ├── 📁bookmarks/
│   ├── 📁collections/
│   ├── 📁recent-searches/
│   ├── 📁saved-searches/
│   └── 🧩layout
│
└── 🧩app.component
```

| Folder/Component            | Description                                                                                               |
| ----------------------------| --------------------------------------------------------------------------------------------------------- |
| 📁 assistant/               | Contains the layout for the assistant feature.                                                            |
| 📁 home/                    | This is the landing page. It displays the most recently viewed documents, recent searches, and bookmarks. |
| 📁 search/                  | Contains the **search** page layout and its subpages.                                                     |
| 📁 search/all/              | Contains the component(s) that will be used to display search results for the "All" tab.                  |
| 📁 widgets/bookmarks/       | Contains components related to bookmarks widget.                                                          |
| 📁 widgets/collections/     | Contains components related to collections widget.                                                        |
| 📁 widgets/recent-searches/ | Contains components related to recent searches widget.                                                    |
| 📁 widgets/saved-searches/  | Contains components related to saved searches widget.                                                     |
| 🧩 widgets/layout           | Layout component for widgets section.                                                                     |
| 🧩 app.component            | The main application component.                                                                           |

:::note
It is possible to use different components for each tab or for each type of returned documents. For this, you need to look at the file _app/registry/document-type-registry.ts_.

For simplicity reasons, in "Mint" we use only one component to display a result regardless of the tab or its type (html, pdf, slide...)
:::
