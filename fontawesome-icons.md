# FontAwesome Icons Used in Mint

50 unique icons, referenced via CSS classes (`far` / `fas` / `fal` + `fa-<name>`). No JS imports from `@fortawesome`.

Typical pattern: `fa-fw <weight> fa-<icon-name>`

All icons have been replaced by custom SVG components in `@sinequa/ui`, using [Lucide](https://lucide.dev/icons/) as the source.
