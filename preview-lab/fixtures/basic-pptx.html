How to Run a SBA App?
8
The first SBA App delivered in Sinequa ES is an Angular application. An Angular application is composed by components, templates and services
Theses applications are not understandable by the browser directly, so a compilation is needed for building all resources (HTML pages, Javascript, Stylesheets, …)
Compilation actions are available in the “build” menu of your App
Note: The SBA sample “_classic” is shipped compiled, it means that it is already usable
Applications are accessible at URLs:
“http://<server>/app/<AppName>”: Build Release
“http://<server>/app-debug/<AppName>”: Debug Release

Note: Shortcuts are available in the “Test” menu of your App

How to create your own App?
13
Use the wizard or follow this workflow:
Copy the “_classic” App. It will also copy all objects below the app (result list, facets, …).
[optional] Copy the query “_default” and assign it to your new app.
In Resources, create a new SBA Application.
Set the Reference package to /@sinequa/classic-angular/.
In the More actions menu, click on Update from reference.
In the Build menu, click on Create build environment.
In your App, set the SBA Application to the new one.
Build your app (“Build” menu) and test it!

14
